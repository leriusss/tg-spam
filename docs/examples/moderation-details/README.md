# Примеры «Подробнее»

Данные синтетические. PNG, HTML, JSON и TXT получены из настоящих operatorDetailPages,
technicalDetailPages и detailKeyboard; отдельной ручной версии карточек нет.
JSON сохраняет все страницы и подписи реальных клавиатур. TXT — читаемый полный текст
без незначащих пробелов на концах строк экспорта; исходный Card.Text не меняется.
HTML/PNG — предпросмотр, не Telegram-клиент; шрифты/переносы клиента могут отличаться.
